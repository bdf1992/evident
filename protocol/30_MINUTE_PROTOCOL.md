# 30-Minute Session Protocol

Pre-session factual seed preparation may happen before the timer. The timed session begins when scope/consent questioning begins.

### 0:00-0:03 — Bind session
Create scope/consent receipt and source boundaries.

### 0:03-0:07 — Register + pre-interview prediction
Register provisional coordinates. Freeze a small prediction set before substantive participant answers.

### 0:07-0:18 — Interview
Adaptive probes. Prefer 5-10 high-information distinctions over question count.

### 0:18-0:23 — Evidence + prediction test
Inspect only high-value sources. Mark predictions supported/narrowed/contradicted/unresolved/not-tested.

### 0:23-0:27 — Participant review
Expose placement, uncertainty, negative boundaries, and prediction deltas. Record challenges.

### 0:27-0:30 — Compile + seal
No new exploratory questions. Write outputs and generate trust receipt/manifest.

## Budget behavior
When behind: preserve provenance, prediction freeze, participant correction, negative boundaries, and sealing; reduce breadth and mark unknowns.
