# Changelog

## 0.3.0 — discovery grammar and relation data
- Added an organizational discovery playbook centered on work, flow, power, boundaries, dependencies, failure, time, evidence, and unknowns.
- Added a probe-priority heuristic and claim-neighbor branching rule so adaptive interviews resolve consequential distinctions rather than complete categories.
- Added a recovery traversal from work through routing for unfamiliar or stalled interviews.
- Added worked cases for an operational team member, AI session operator, small-company founder, and federated organization.
- Added a canonical optional machine-readable relation schema with provenance, perspective, valid time, qualifiers, and routing safety.
- Added operator identity and operator/participant relationship to session metadata.
- Strengthened challenge guidance to expose falsifiable relations, boundaries, authority limits, and routing implications.
- Preserved the compressed core skill while moving heavier investigation guidance into protocol documents.

## 0.2.0 — session, prediction, trust
- Made Session a first-class primitive and output boundary.
- Added frozen pre-interview predictions based on supplied/common factual evidence.
- Added explicit prediction-delta statuses: supported, narrowed, contradicted, unresolved, not-tested.
- Added participant challenge ledger.
- Added SHA-256 manifest + trust receipt and verification tool.
- Added append-only session federation guidance.
- Renamed run tooling/schema to session tooling/schema.

## 0.1.0 — bootstrap
- Defined 30-minute hard budget.
- Added evidence-state and perspective invariants.
- Added adaptive probe families rather than a fixed questionnaire.
- Added participant placement with negative routing/authority boundaries.
- Added frontier-model operator guide, factual seed template, synthetic fixture, schemas, and validator.
